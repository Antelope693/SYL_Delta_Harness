========================================
  SYL Delta Harness  使用说明
========================================

【一、这是什么】
本程序已编译为独立 EXE，目标电脑
无需安装 AutoHotkey，解压后双击即可运行。

【二、目录结构】
SYL_Delta_Harness\
├─ SYL_Delta_Harness.exe      ← 双击这个运行（独立程序，无需安装 AHK）
├─ SYL_Delta_Harness.ahk      ← 脚本源码备份，一般不用单独打开
├─ WifiLib\                    ← 断网驱动与提示音资源，请勿删除/改名
│   ├─ WinDivert.dll
│   ├─ WinDivert64.sys
│   ├─ Start.mp3
│   └─ end.mp3
└─ 使用说明.txt

【注意事项】
1. 必须以管理员身份运行，否则驱动加载失败、断网功能不可用。
2. 请勿删除或移动 WifiLib 文件夹，四个资源文件缺一不可；exe 与
   WifiLib 必须放在同一目录下。
3. 本程序为 64 位 Windows 版本。
4. 首次运行会在程序目录自动生成 Config 配置文件夹，属正常现象。
5. 杀毒软件可能对 WinDivert 驱动或打包程序误报，如被拦截请添加信任后重试。
